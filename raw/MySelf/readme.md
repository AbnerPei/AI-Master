## 这个文件夹是做什么的

这个 `raw/MySelf` 文件夹，专门用来放和“我自己”有关的一手资料，让 `AI` 更稳定地理解你，而不是每次只根据当前对话临时猜。

这里适合放“原始、自述、长期有效”的内容，不必一开始就写得很正式。先把真实信息放进来，后面再逐步整理成更结构化的内容。

## 建议优先放什么

- `01_我是谁.md`：你的身份、角色、长期目标、当前阶段。
- `02_我在做什么.md`：你现在重点在做的项目、方向、想解决的问题。
- `03_我的工作方式.md`：你喜欢怎样协作、怎样接收建议、怎样推进任务。
- `04_我的判断标准.md`：你认为什么是高质量结果，什么是不能接受的结果。
- `05_我不喜欢什么.md`：你反感的表达方式、低质量行为、常见误判。
- `06_近期关注主题.md`：你最近最想深入的主题、领域、关键词。

## 哪些信息最有价值

- 稳定信息：你的长期兴趣、职业方向、常驻项目、常用工具。
- 决策偏好：你做选择时最看重什么，比如速度、准确性、可复用性、可维护性。
- 协作偏好：你喜欢 `AI` 先诊断再改，还是先给方案再执行。
- 表达偏好：你喜欢简洁、细节型、结构化，还是案例驱动的说明。
- 反面清单：哪些建议对你没用，哪些废话你不想再看。

## 填写建议

- 尽量写具体事实，不要只写抽象标签。
- 多写“我通常会……”而不是“我希望自己……”。
- 如果一个偏好已经被反复验证过，就单独成文，方便后续引用。
- 可以保留阶段性变化，因为 `AI` 也需要知道什么是长期规则，什么只是当前状态。

## 一个很实用的写法

你可以把每篇文档都尽量写成下面这种形式：

- 我目前的情况是什么。
- 我为什么这样做。
- 我希望 `AI` 怎么配合我。
- 什么样的建议对我有帮助。
- 什么样的建议是在浪费时间。

## 后续建议

如果你愿意，下一步最值得先补的是 `01_我是谁.md` 和 `03_我的工作方式.md`。这两个文件对 `AI` 建立稳定认知最直接。
