| 状态                                           | 描述                                 |
| -------------------------------------------- | ---------------------------------- |
| 已修改（modified）                                | 表示修改了文件，但是还没有保存到数据库中。              |
| **<font color="#e36c09">已暂存（staged）</font>** | 表示对一个已修改文件的当前版本做了标记，使之包含在下次提交的快照中。 |
| 已提交（committed）                               | 表示数据已经安全地保存在本地数据库中。                |
