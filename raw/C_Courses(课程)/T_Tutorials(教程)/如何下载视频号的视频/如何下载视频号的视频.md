### wx_channels_download（推荐）

| 项目 | 说明 |
|------|------|
| GitHub | https://github.com/ltaoo/wx_channels_download |
| 平台 | macOS (ARM/x86) + Windows |
| 原理 | 修改系统代理，拦截微信网络请求，注入下载按钮 |
| 当前版本 | `v260502` |
![[wx_channel_video_003.png]]
**macOS 安装：**
> [macOC运行](https://ltaoo.github.io/wx_channels_download/guide/macos.html) `文档`
```bash
# 下载对应芯片版本：
#   arm64: wx_video_download_darwin_arm64
#   x86_64: wx_video_download_darwin_x86_64

cd ~/Downloads/wx_video_download_v260502_darwin_arm64
chmod +x wx_video_download

# 首次需要 sudo（安装证书）
sudo ./wx_video_download

# 后续直接双击即可
```

![[wx_channel_video_001.png]]

**使用步骤：**

1. 运行 `wx_video_download`，保持终端打开
2. 打开 **Mac 微信 → 视频号**
3. 找到目标视频 → **播放 → 暂停**
4. 视频下方出现 **"下载"** 按钮 → 点击
5. 视频保存在 `~/Downloads/`

> ⚠️ 关键：必须先播放再暂停，下载按钮才有效
> ⚠️ 网页链接（channels.weixin.qq.com/...）无法直接下载视频

![[wx_channel_video_002.png]]

## 常见问题

### Q1: 为什么无法直接从链接下载视频？

视频号网页版（`channels.weixin.qq.com`）是纯 JS 渲染的静态分享卡片，不提供视频流。视频只通过微信 App 传输。

### Q2: 下载的视频文件在哪？

`wx_channels_download` 下载的文件默认保存在 `~/Downloads/`：
