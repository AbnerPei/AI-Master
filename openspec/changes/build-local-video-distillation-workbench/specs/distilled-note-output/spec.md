## ADDED Requirements

### Requirement: 标准化输出产物
对每个成功完成的本地视频蒸馏任务，系统 MUST 生成一组标准输出产物。

#### Scenario: 写入标准文件
- **WHEN** 任务成功完成
- **THEN** 输出目录至少包含任务元数据、原始转录、清洗转录和一份 `AI` 蒸馏文档

### Requirement: 尊重用户选择的输出目录
系统 MUST 把生成结果写入用户选择的目录，而不是强制要求固定仓库路径。

#### Scenario: 写入所选目录
- **WHEN** 用户选择了一个可写输出目录
- **THEN** 生成文件写入该目录下

### Requirement: 蒸馏结果必须可追溯
系统 MUST 让最终 `AI` 总结能够回溯到转录层和任务元数据。

#### Scenario: 蒸馏结果可回看原始上下文
- **WHEN** 产出 `AI` 蒸馏文档
- **THEN** 配套产物仍然保留源转录和任务元数据，方便后续复查总结是如何得出的

### Requirement: 失败任务仍然可诊断
任务失败后，系统 MUST 保留足够的元数据和日志，以便后续诊断。

#### Scenario: 保留失败证据
- **WHEN** 任务启动后失败
- **THEN** 输出区域或任务状态保留相关阶段、错误描述和可用的部分日志
