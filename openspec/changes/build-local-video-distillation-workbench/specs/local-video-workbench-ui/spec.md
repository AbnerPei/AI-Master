## ADDED Requirements

### Requirement: 本地视频工作台输入表单
系统 MUST 提供一个本地工作台界面，让用户在启动任务前选择一个本地视频文件和一个输出目录。

#### Scenario: 选择本地 `mp4`
- **WHEN** 用户打开工作台
- **THEN** 界面提供清晰的方式来选择本地 `mp4` 文件

#### Scenario: 选择输出目录
- **WHEN** 用户准备运行任务
- **THEN** 界面提供清晰的方式来选择生成结果的输出目录

### Requirement: 阻止模糊启动
当必填输入缺失或无效时，系统 MUST 阻止任务启动。

#### Scenario: 缺少输入时禁止启动
- **WHEN** 用户还没有选择视频文件或输出目录
- **THEN** 工作台不允许启动任务，并提示缺少哪个必填字段

### Requirement: 完成后可见结果
任务完成后，系统 MUST 在工作台中展示生成结果。

#### Scenario: 展示生成结果
- **WHEN** 任务成功完成
- **THEN** 工作台展示生成的结果文件及其所在位置
